# Дизайн: курс «Изучение Библии в малых группах»

**Дата:** 2026-05-13
**Статус:** Утверждён
**Тип:** Новый раздел сайта

## Цель

Добавить третий курс на сайт `uchenichestvo` (после `burnham/` и `7-shagov/`) — справочник тем для разборов Библии в малых группах. Курс охватывает 102 темы: 52 Ветхого Завета и 50 Нового Завета. Для каждой темы у пользователя должны быть под рукой:

1. Полный текст изучаемого отрывка в Синодальном переводе.
2. Вопросы для разбора в двух редакциях — собственные вопросы пользователя и вопросы из справочника Эдуарда Гагенганса «Изучение Библии в малых группах» (Bible Mission, 2024).
3. Подготовительные медиа-материалы (аудио, картинки; в будущем — другие форматы).

## Источники

Все исходники находятся в `groups/row_material/`:

- `Вопросы_Ветхий_Завет_1-52.pdf` — 52 страницы, по 1 теме на страницу. Формат: `№. Название (Ссылка)` + блоки **Введение / Наблюдение / Понимание / Применение**. Темы сгруппированы римскими секциями (I, II, …).
- `Вопросы_Новый_Завет_51-100.pdf` — 50 страниц, аналогичная структура (нумерация 51–100).
- `Изучение_Библии_в_малых_группах_для_лидеров.pdf` — справочник Гагенганса, 68 страниц. Первые 10 страниц — методическое введение. С с. 11 идут вопросы по тем же 102 темам: подзаголовок `a. Название (Ссылка)` + три блока с иконками ☕ (введение), 📖 (наблюдение/понимание), ❤️ (применение).
- `data example 43. Призвание Иеремии/` — образец медиа на тему: 2 аудио (`.m4a`) и 3 картинки (`.png`).

Существующая база Синодального перевода: `data/synodal.json` (66 книг, индексы с 0).

## Хаб курса (`bible-groups/index.html`)

Простая страница с двумя крупными карточками:

- «Ветхий Завет — 52 темы» → `ot.html`
- «Новый Завет — 50 тем» → `nt.html`

Краткое описание курса (1–2 абзаца) сверху. Тёмный/светлый toggle и стилизация — как в остальных курсах.

## Страницы списков (`ot.html`, `nt.html`)

Загружают `topics.json`, фильтруют по `testament`, рендерят список.

**Шапка:**

- Хлебные крошки `← К курсу`
- Поле поиска `<input type="search">` с placeholder «Поиск по номеру, названию или ссылке…»
- Тёмный/светлый toggle

**Список:**

Темы сгруппированы по секциям из PDF (римские заголовки: «I. В начале», «II. …»). Каждая тема — ссылка-карточка:

```
1. Пролог (Бытие 1:1–2:4)        🔊 🖼
2. Эдемский сад (Бытие 2:5–25)
3. Грехопадение (Бытие 3)         🔊
```

Иконки 🔊 / 🖼 показываются, если в `media[id]` соответствующий массив непустой. Заготовка под `🎬` для видео.

**Поиск:**

Чистый клиентский live-фильтр. Совпадение по любому из:

- Номеру (точное `1`, `01`, `1.`)
- Названию (подстрока, case-insensitive)
- Ссылке (подстрока в `reference`)

При активном поиске секционные заголовки скрываются, если в них нет видимых тем.

## Просмотр темы (`bible-groups/topic.html`)

URL: `topic.html?id=ot-01` (id из `topics.json`).

При загрузке: парсит `id`, находит запись в `topics.json`, отрисовывает шапку (номер, название, ссылка) и три главные вкладки.

### Вкладка 1: «📖 Текст»

Рендерит библейский текст из `data/synodal.json` по `refStructured`. Используется механизм, уже работающий в `burnham/topic.html` и `7-shagov/topic.html` для библейских цитат — если он там вынесен в общий модуль, переиспользуем; если нет, дублируем код локально и оставляем пометку для будущего рефакторинга.

Шрифт текста — Lora, нумерация стихов — мелкая надстрочная, как в остальных конспектах.

### Вкладка 2: «❓ Вопросы»

Содержит две **вложенные** вкладки:

- **«Мои»** — рендер `{testament}/{NN-slug}-mine.md` через marked.js.
- **«Гагенганс»** — рендер `{testament}/{NN-slug}-hagen.md` через marked.js. Заголовки трёх блоков (введение/наблюдение/применение) в Markdown — обычные `##`, иконки добавляются через CSS-префикс или эмодзи в самом заголовке Markdown.

Активная вложенная вкладка запоминается в `localStorage` (ключ `bibleGroupsQuestionsTab` со значением `mine` или `hagen`), чтобы при переходе между темами не приходилось переключать заново.

### Вкладка 3: «🎧 Подготовка»

Список медиа из `media[id]`:

- **Аудио** — каждый файл оборачивается `<audio controls preload="none" src="media/NN-slug/audio-N.m4a">`. Над плеером — название (если оно есть в метаданных) или имя файла без расширения.
- **Картинки** — `<img>` с `loading="lazy"`. По клику открывается полноэкранный лайтбокс (простая overlay-реализация без библиотеки).

Если медиа для темы нет — вкладка показывает плейсхолдер «Подготовительные материалы пока не добавлены».

Каркас вкладки спроектирован под будущие форматы (`video`, `link`, `pdf`): рендерер группирует медиа по типу, новые типы добавляются как новые секции.

### Состояние вкладок

Активная главная вкладка тоже сохраняется в `localStorage` (ключ `bibleGroupsMainTab`, значения `text` / `questions` / `prep`). По умолчанию открывается «Текст».

## Формат `topics.json`

Массив из 102 записей. Сортировка по `number`.

```json
[
  {
    "id": "ot-01",
    "testament": "ot",
    "number": 1,
    "section": "I. В начале",
    "title": "Пролог",
    "reference": "Бытие 1:1–2:4",
    "refStructured": {
      "book": "gn",
      "from": [1, 1],
      "to": [2, 4]
    },
    "slug": "01-prolog",
    "media": {
      "audio": [],
      "image": []
    }
  }
]
```

Поля:

- `id` — строка `{testament}-{NN}`, где NN с ведущим нулём (`ot-01`, `nt-51`). Используется в URL и как ключ.
- `testament` — `"ot"` или `"nt"`.
- `number` — целое 1..100. Темы НЗ нумеруются 51..100 (как в исходнике).
- `section` — заголовок секции из PDF (например, «II. Закон»).
- `title` — название темы.
- `reference` — человекочитаемая ссылка (с en dash `–`).
- `refStructured` — для рендера текста: `{ book, from: [chapter, verse], to: [chapter, verse] }`. `book` — abbrev из `data/synodal.json`. Для диапазонов через запятую/точку (типа «Бытие 1; 3; 12») используем массив `passages: [{from, to}, …]` — таких тем единицы, проверяется при извлечении.
- `slug` — латинская транслитерация, используется в именах .md и папок media.
- `media` — массивы относительных имён файлов в `bible-groups/media/{slug}/`. Пустые массивы для тем без подготовки.

## Извлечение данных из PDF

Одноразовый Python-скрипт `scripts/extract_bible_groups.py`:

1. Парсит оба PDF с вопросами и PDF Гагенганса (с с. 11).
2. Извлекает: номер темы, секцию, название, библейскую ссылку, четыре блока вопросов.
3. Генерирует `topics.json` (без `media` — заполняется отдельно), `ot/*.md`, `nt/*.md`.
4. Транслитерирует названия в слаги.

Скрипт сохраняется в `scripts/` и в исходниках курса — для повторного запуска при правках PDF. Зависимости: `pdfplumber` или `pymupdf` (выберется на этапе плана). Запускается вручную через `python3 scripts/extract_bible_groups.py`.

**Парсинг библейских ссылок:** отдельная функция «`Бытие 1:1–2:4`» → `refStructured`. Карта русских названий книг → abbrev из `synodal.json` лежит в скрипте. Ссылки с разрывами («Бытие 1; 3; 12») → `passages: [...]`.

После запуска скрипта — ручная проверка нескольких тем на корректность (особенно сложных ссылок) и финальный коммит.

## Тестирование

UI/контентный проект, формальных тестов нет. Чек-лист ручной проверки:

1. Открыть `bible-groups/` — хаб виден, ссылки работают.
2. Открыть `ot.html` — список из 52 тем с правильными секциями, поиск работает по номеру/названию/ссылке.
3. Открыть `nt.html` — то же для 50 тем НЗ.
4. Открыть `topic.html?id=ot-01`:
   - Текст из Бытия 1:1–2:4 отображается полностью.
   - Вкладка «Вопросы → Мои» показывает 4 блока.
   - Вкладка «Вопросы → Гагенганс» показывает 3 блока с иконками.
   - Вкладка «Подготовка» — плейсхолдер (медиа нет).
5. Открыть `topic.html?id=ot-43` (Призвание Иеремии): на вкладке «Подготовка» 2 аудиоплеера и 3 картинки. В списке `ot.html` рядом с темой 43 видны иконки 🔊 🖼.
6. Переключатель тёмной темы работает на всех новых страницах.
7. На мобильном (узкое окно) вкладки и контент читаемы.
