### 3. Изучение Библии в малых группах

102 темы для разборов в малых группах: 52 Ветхого Завета и 50 Нового Завета. Источники: PDF-сборники вопросов автора и справочник Эдуарда Гагенганса «Изучение Библии в малых группах» (Bible Mission, 2024).

- [Хаб курса](bible-groups/)
- [Ветхий Завет (52 темы)](bible-groups/ot.html)
- [Новый Завет (50 тем)](bible-groups/nt.html)

Каждая тема включает:
- **Текст** – полный отрывок из Синодального перевода
- **Вопросы** – две редакции: авторская и Гагенганса (для ВЗ); НЗ – только авторская
- **Подготовка** – аудио и картинки для подготовки к разбору

## Регенерация данных (курс 3)

Извлечение вопросов из PDF и обновление медиа-индекса:

```bash
python3 scripts/extract_bible_groups.py   # PDF → bible-groups/{ot,nt}/*.md + topics.json
python3 scripts/scan_media.py             # bible-groups/media/ → media-блоки в topics.json
```

Зависимости: `pdfplumber` (`python3 -m pip install --user pdfplumber`).
