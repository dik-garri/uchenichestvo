# Ученичество – Project Conventions

## Overview
Материалы для личного ученичества. Два курса: «Преображающее знакомство со Христом» (17 тем) и «Семь шагов христианской жизни» (7 уроков). Размещены на GitHub Pages.

## Structure
```
uchenichestvo/
├── index.html                         # Hub – выбор курса
├── burnham/                           # Курс 1: Преображающее знакомство со Христом
│   ├── index.html                     # Список 17 тем
│   ├── topic.html                     # Просмотр темы (marked.js)
│   ├── TEMPLATE.md                    # Шаблон для конспектов
│   └── NN-тема.md                     # Конспекты (17 файлов)
├── 7-shagov/                          # Курс 2: Семь шагов христианской жизни
│   ├── index.html                     # Список 7 шагов
│   ├── topic.html                     # Просмотр темы (marked.js)
│   └── NN-тема.md                     # Конспекты (7 файлов)
├── data/
│   └── synodal.json                   # Синодальный перевод (из church.kg) – 66 книг
├── CLAUDE.md
└── README.md
```

### Структура конспекта (burnham)
- Шаблон: `burnham/TEMPLATE.md`
- Темы 1–8 (ВЗ): Часть 1 (объяснение темы) + Часть 2 (христологический взгляд)
- Тема 9: историческая глава (без Части 2)
- Темы 10–17 (НЗ): единая структура без деления на части
- Каждый конспект включает: основной текст, контекст, разбор, вопросы для обсуждения, практические выводы

## Bible Quotes
- All scripture texts MUST be exact copies from the Synodal translation (Синодальный перевод)
- **Primary source:** `data/synodal.json` – локальная копия Синодального перевода из проекта church.kg
  - Структура: массив из 66 книг, каждая `{ "abbrev": "lk", "chapters": [[стих1, стих2, ...], ...] }`
  - Индексы: книги с 0, главы с 0, стихи с 0
- НЕ использовать WebFetch для получения текстов Библии – он обрезает текст
- Never paraphrase or quote from memory

## Typography
- Use en dash `–` (среднее тире) everywhere, NOT em dash `—`
- In HTML use `&ndash;` entity

## Design
- Light theme by default, dark theme available via toggle
- Fonts: Montserrat (headings/body), Lora (scripture)
- Colors (dark): background `#0F1B2D`, gold `#D4A843`
- Colors (light): background `#F5F3EF`, gold `#9A7B2D`
- Language: Russian
